# Instructions for Claude

## Delivering content

- Give every piece of content (handouts, credit lines, drafts) in the chat as plain text inside a fenced code block, so it pastes cleanly into a document.
- The chat copy uses no Markdown symbols: no `#`, `**`, `*`, link brackets, or image tags. Use CAPS for headings, `1.` for steps, `•` for bullets, and write web addresses out in full. Put `[Insert ... image here]` where an image goes.
- Do not send content to the side panel viewer (rendered file cards or artifacts) unless asked.
- Save the same content as a Markdown `.md` file in this repo, then commit and push it to GitHub.
- Never use DOCX. Markdown only.
