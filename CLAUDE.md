# Instructions for Claude

## Delivering content

- Give every piece of content (handouts, credit lines, drafts) in the chat as regular formatted text that the user can select, copy, and paste into a document with formatting intact.
- Do not put content inside code blocks (grey boxes). Do not send content to the side panel viewer (rendered file cards or artifacts) unless asked.
- Set the content apart with a horizontal rule above and below it. Use bold CAPS for the title and section headings, numbered lists for steps, bullets for checklists, and italics for image credits. Write web addresses out in full. Put `[Insert ... image here]` where an image goes.
- Save the same content as a Markdown `.md` file in this repo, then commit and push it to GitHub.
- Never use DOCX. Markdown only.
